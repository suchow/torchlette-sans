# Codekeys auxiliary outlines

`auxiliary_codekeys.py` emits fourteen complete auxiliary TTFs containing raw
outlines for exactly `uni238B`, `uni266D`, and `flat.note.codekeys`. This first
profile supports only the explicitly declared current15 source/module context.
Revalidation against the final combined module context is still pending. It
neither changes ordinary module defaults nor builds or accepts a variable font.
The polished originals remain the independent oracle.

## Inputs and tools

Use Python 3.12, fonttools 4.68.0, skia-pathops 0.9.2, and brotli 1.2.1.
Required inputs are:

- A source directory containing hash-pinned `build.py`, `modules/codekeys.py`, and
  `Makefile`, plus these two emitter/bootstrap scripts.
- Fourteen authoritative polished `TorchletteSans-*.ttf` originals, from Light
  through Black in genuine Roman and italic styles.
- Fourteen explicit donor instances and their manifest. They are inputs, not
  regenerated by this command. The ordinary Makefile donor targets show how to
  instance the licensed Mulish Roman/italic source fonts at the declared weights
  with the pinned fontTools. Supply both genuine styles; do not synthesize italics.
- A hashed config with explicit source parameters and module context.

The donor manifest is JSON with exact fields `schema: torchlette-donor-instances`,
`version: 1`, and `faces`. Each of its fourteen rows is:

```json
{
  "weight": 300,
  "ital": 0,
  "source_weight": 242,
  "file": {"path": "Mulish-242.ttf", "sha256": "ACTUAL_LOWERCASE_SHA256"}
}
```

Paths resolve beside the manifest. Other source weights are Regular 324, Medium
388, SemiBold 510, Bold 675, ExtraBold 762 and Black 845; matching italic styles
use the same weights. The pinned Makefile is checked rather than trusting these
labels alone. Input font licensing and provenance remain the caller's original
source artifacts; the auxiliaries preserve the originals' metadata.

The config's exact fields are `schema: torchlette-codekeys-cold-source`,
`version: 1`, `source_files` (those three relative source paths mapped to SHA256),
`originals` (all fourteen standard filenames mapped to SHA256),
`donor_manifest_sha256`, numeric `params`, `modules`, generation `pins`,
`source_commit`, and `bootstrap_sha256`. The legacy name `source_commit` holds the
caller's declared source working-tree lineage; hashes identify the actual bytes.
It does not assert that this emitter or a dirty source tree exists in that commit.
The emitted manifest records this lineage and the executed emitter hash explicitly.
`params: {}` selects source defaults; ambient tuning variables are not consulted.

The only accepted module list, in order, is:

```
codekeys cyrillic fleurons greek kern lnum mathletters mathnotation meta
 otfeatures sigmoid supsub symbols tensordiagram ui
```

This records the original fonts' context. It does not run modules or enable Greek
or any other module in an ordinary build. Other contexts require a separately
reviewed profile and original-static verification.

## Hash-bound invocation

The bootstrap executes the emitter's verified byte snapshot. Its own verified
body is passed as a literal Python `-c` argument, so the recorded command binds
the executed bootstrap too. The following is runnable after choosing the paths
and preparing the donor manifest above. Keep the config and new output outside
the source/original directories. `SOURCE_LINEAGE` should describe the source
checkout/snapshot honestly, including relevant working-tree changes.

```sh
SOURCE_ROOT=/absolute/path/fonts/torchlette-sans \
MASTERS=/absolute/path/fourteen-originals \
DONORS=/absolute/path/donors.json \
CONFIG=/absolute/scratch/codekeys-config.json \
OUTPUT=/absolute/scratch/new-auxiliaries \
SOURCE_LINEAGE='reviewed source snapshot or HEAD plus declared working-tree changes' \
PYTHONHASHSEED=0 PYTHONDONTWRITEBYTECODE=1 \
uv run --no-project --python 3.12 \
  --with fonttools==4.68.0 --with skia-pathops==0.9.2 --with brotli==1.2.1 \
  python - <<'PY'
import hashlib, json, os, subprocess, sys
from pathlib import Path
root, masters, donors, config, output = [Path(os.environ[k]).resolve()
    for k in ('SOURCE_ROOT', 'MASTERS', 'DONORS', 'CONFIG', 'OUTPUT')]
digest = lambda raw: hashlib.sha256(raw).hexdigest()
bootstrap = (root / 'run_auxiliary_codekeys.py').read_bytes()
emitter = root / 'auxiliary_codekeys.py'
settings = {
    'schema': 'torchlette-codekeys-cold-source', 'version': 1,
    'source_files': {name: digest((root / name).read_bytes())
        for name in ('build.py', 'modules/codekeys.py', 'Makefile')},
    'originals': {p.name: digest(p.read_bytes())
        for p in masters.glob('TorchletteSans-*.ttf')},
    'donor_manifest_sha256': digest(donors.read_bytes()), 'params': {},
    'modules': 'codekeys cyrillic fleurons greek kern lnum mathletters mathnotation '
        'meta otfeatures sigmoid supsub symbols tensordiagram ui'.split(),
    'pins': {'fonttools': '4.68.0', 'skia-pathops': '0.9.2', 'brotli': '1.2.1'},
    'source_commit': os.environ['SOURCE_LINEAGE'],
    'bootstrap_sha256': digest(bootstrap),
}
# Refuse to replace an existing evidence config.
with config.open('x') as stream:
    json.dump(settings, stream, indent=2)
    stream.write('\n')
config_raw = config.read_bytes()
if digest(bootstrap) != settings['bootstrap_sha256']:
    raise ValueError('Bootstrap snapshot differs from config')
code = '_BOOTSTRAP_SHA=' + repr(digest(bootstrap)) + '\n' + bootstrap.decode()
command = [sys.executable, '-c', code, '--emitter', str(emitter),
    digest(emitter.read_bytes()), '--source-root', str(root), '--masters', str(masters),
    '--donors-manifest', str(donors), '--config', str(config),
    '--config-sha256', digest(config_raw), '--out-dir', str(output)]
environment = {k: v for k, v in os.environ.items()
    if k in ('PATH', 'HOME', 'TMPDIR', 'LANG', 'LC_ALL', 'UV_CACHE_DIR')}
environment.update(PYTHONHASHSEED='0', PYTHONDONTWRITEBYTECODE='1')
subprocess.run(command, env=environment, check=True)
PY
```

For an already approved config, pass its recorded hashes rather than recreating
it from mutable sources. The emitter CLI has required `--source-root`, `--masters`,
`--donors-manifest`, `--config`, `--config-sha256`, and `--out-dir` arguments; use
`--help` through the same bootstrap. Direct unverified emitter execution rejects.
Python optimization and ambient `PYTHONPATH`/`PYTHONOPTIMIZE` are refused.

## Geometry and provenance

Every source and font is read once into a verified byte snapshot. Required source
expressions are selected by structural data dependencies, not fixed line spans.
There are no historical helper imports, prior raw-clone inputs or geometry caches.
Installed third-party packages are version-pinned; that is not a claim of
cross-platform binary reproducibility.

The emitter preserves source cubic controls and exact clipping roots, joint
fourteen-style 0.125-unit cu2qu conversion, and the original integer → italic
reslant → integer stages. It deliberately retains the analytic JSON boundary:
list/tuple closing-point handling affects TTGlyphPen's encoded point structure.
No extra polish, fitting, redraw or point deletion is introduced.

Each output starts directly from its polished original. Only the three selected
simple outlines and representation-dependent LSBs change; original advances and
rendered origins remain authoritative. Other glyphs, metrics, cmap, layout and
metadata are preserved. Raw outlines have `OVERLAP_SIMPLE` set. Analytic fill and
computed source advances must agree exactly before output.

Outputs are `fonts/*.ttf`, `auxiliary-manifest.json` in the `variable.py` intake
schema, `analytic.json`, `source-stage-records.json`, and `emission-proof.json`.
The proof records executed emitter/bootstrap hashes, all inputs, explicit context,
tools and environment. The manifest's generator source is the executed emitter;
its config binds source and donor/original hashes. Existing output directories,
symlink roots, input aliases, unknown schema/context and hash drift reject. All
inputs are rehashed against their original expected digests at completion.
These checks do not create a filesystem-wide lock against hostile concurrency.

## Verification boundary

The reviewed cold profile had two independent emissions whose fourteen complete
fonts were byte-identical to the sealed three-glyph adapter. The repository port
must repeat that binding and actual intake validation. Only exact font identity
allows reuse of those existing 42 endpoint and 36 intermediate native checks.
This is separate from final family construction and the unchanged original-static
full verifier/corpus gate. An accepted manifest never establishes curve quality,
final-module compatibility, publication readiness, or release approval by itself.
